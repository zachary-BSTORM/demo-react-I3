# Introduction à React

## 1. Créer et lancer un projet

| Commande | Rôle |
|---|---|
| `node -v` | Affiche la version de Node installée |
| `npm create vite@latest` | Crée un nouveau projet (choisir **React**, puis **JavaScript**) |
| `npm i` (ou `npm install`) | Installe les dépendances listées dans `package.json` |
| `npm run <script>` | Lance un script défini dans `package.json` |
| `npm run dev` | Démarre le projet en développement (http://localhost:5173) |

```bash
npm create vite@latest mon-projet
cd mon-projet
npm i
npm run dev
```

## 2. Le composant

- Un **composant** est une **fonction JavaScript** qui **renvoie du JSX**.
- Son nom commence par une **majuscule** : `App`, `MonComposant`.

Dans un composant, on peut :

- **déclarer** des variables et des fonctions ;
- **utiliser** d'autres composants dans le JSX renvoyé.

```jsx
import Titre from "./components/Titre";

function App() {
  // une variable
  const prenom = "Ana";

  // une fonction
  function direBonjour() {
    return `Bonjour ${prenom} !`;
  }

  // le JSX renvoyé, qui utilise un autre composant
  return (
    <div>
      <Titre />
      <p>{direBonjour()}</p>
    </div>
  );
}

export default App;
```

## 3. Le rendu et le DOM virtuel

- React garde en mémoire une copie de l'interface : le **DOM virtuel**.
- Quand une donnée change, React compare la nouvelle version à l'ancienne et ne modifie dans la page que **ce qui a changé**.
- ⚠️ Modifier une **variable normale** ne met **pas** la page à jour : le composant n'est pas rendu à nouveau.

## 4. Le hook `useState`

Pour qu'une valeur change à l'écran pendant l'exécution, on utilise un **hook** : `useState`.

```jsx
const [valeur, setValeur] = useState(valeurParDefaut);
```

- `valeur` : la valeur actuelle ;
- `setValeur` : la fonction qui modifie la valeur **et** relance le rendu du composant ;
- `valeurParDefaut` : la valeur de départ.

```jsx
import { useState } from "react";

function App() {
  const [compteur, setCompteur] = useState(0);

  return (
    <button onClick={() => setCompteur(compteur + 1)}>
      Cliqué {compteur} fois
    </button>
  );
}

export default App;
```

> On ne modifie jamais la valeur directement (`compteur++`) : on passe toujours par `setCompteur`.

## 5. Le style

| Portée | Où | Exemple |
|---|---|---|
| **Global** (toute l'application) | `index.css`, importé dans `main.jsx` | `body { font-family: sans-serif; }` |
| **Propre à un composant** | Un fichier CSS importé dans le composant | `import "./Carte.css";` |
| **En ligne** (inline) | L'attribut `style`, qui reçoit un **objet** | `<p style={{ color: "red" }}>` |
| **Objet de style** | Un objet déclaré dans le composant, puis passé à `style` | voir ci-dessous |

```jsx
function Alerte() {
  const styleAlerte = {
    color: "white",
    backgroundColor: "crimson", // propriétés en camelCase
    padding: "8px",
  };

  return <p style={styleAlerte}>Attention !</p>;
}
```

> En JSX, on écrit `className` à la place de `class` : `<p className="alerte">`.
